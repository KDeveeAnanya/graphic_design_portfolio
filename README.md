# K. Devee Ananya — Portfolio

React + Vite. `npm install`, then `npm run dev`. `npm run build` for production.

## Edit your content
- `src/data/site.js` — email, social links (they appear in Contact automatically), year.
- `src/data/projects.js` — case studies: copy, palette, and the numbered hotspots (x / y are % of the image). Also the "Also worked with" list.
- `src/assets/work/` — drop new project images here and import them in `projects.js`.
- `src/data/lab.js` — add an experiment: write a component in `src/components/lab/`, add one entry.

## Easter eggs
Press `Ctrl/Cmd + K` (or `/`) for the command menu. Open the browser console. Try `sudo create` in Contact.
